  <files>app/src/main/AndroidManifest.xml, gradle/libs.versions.toml</files>
  <action>
**AndroidManifest.xml** — Add `android:extractNativeLibs="true"` to the `<application>` tag.

Find the existing `<application>` opening tag (line 22-34 of the current file). Add the attribute on a new line between `android:networkSecurityConfig="@xml/network_security_config"` and `tools:targetApi="34"`:

```xml
    android:networkSecurityConfig="@xml/network_security_config"
    android:extractNativeLibs="true"
    tools:targetApi="34">
```

Do NOT add `android:requestLegacyExternalStorage` — the app uses MediaStore and scoped storage correctly. Do NOT change any other manifest attributes.

**Why:** The youtubedl-android library packages Python 3.8 and yt-dlp as native `.so` files. Without `extractNativeLibs="true"`, Android keeps them compressed in the APK and `YoutubeDL.getInstance().init()` throws `YoutubeDLException: failed to initialize` because the Python runtime file path does not exist on disk.

**gradle/libs.versions.toml** — Change the AGP version from the non-existent `8.13.1` to `8.13.2`.

Find line 2: `agp = "8.13.1"` and change to:
```toml
agp = "8.13.2"
```

Do NOT change any other version in the file. Kotlin stays at 1.9.0, Compose BOM stays at 2023.08.00 — those upgrades are deferred to Phase 2.

**Why:** AGP version 8.13.1 does not exist in official releases (only 8.13.0 and 8.13.2). Gradle sync fails with `Could not find com.android.tools.build:gradle:8.13.1`. The Gradle wrapper is already at 8.13 (verified from `gradle-wrapper.properties`), so no wrapper change is needed.

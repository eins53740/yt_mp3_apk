**1. DownloadHistoryEntity.kt** -- Create new file:

```kotlin
package com.example.yt2local.data.db

import androidx.room.ColumnInfo
import androidx.room.Entity
import androidx.room.PrimaryKey

@Entity(tableName = "download_history")
data class DownloadHistoryEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    @ColumnInfo(name = "file_name") val fileName: String,
    @ColumnInfo(name = "platform") val platform: String,
    @ColumnInfo(name = "is_audio") val isAudio: Boolean,
    @ColumnInfo(name = "timestamp") val timestamp: Long,
    @ColumnInfo(name = "media_uri") val mediaUri: String?
)
```

The `mediaUri` field stores the `content://` MediaStore URI string returned by `resolver.insert()`. This is needed for REL-04 (tap-to-open). Nullable because the URI can fail to be captured.

**2. DownloadHistoryDao.kt** -- Create new file:

```kotlin
package com.example.yt2local.data.db

import androidx.room.Dao
import androidx.room.Insert
import androidx.room.OnConflictStrategy
import androidx.room.Query
import kotlinx.coroutines.flow.Flow

@Dao
interface DownloadHistoryDao {
    @Query("SELECT * FROM download_history ORDER BY timestamp DESC LIMIT 10")
    fun getRecent(): Flow<List<DownloadHistoryEntity>>

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insert(item: DownloadHistoryEntity)

    @Query("DELETE FROM download_history WHERE id NOT IN (SELECT id FROM download_history ORDER BY timestamp DESC LIMIT 10)")
    suspend fun pruneOld()
}
```

`getRecent()` returns newest-first, limited to 10 (matches the existing in-memory `take(9)` + 1 behavior). Returns `Flow` for reactive observation by ViewModel. `pruneOld()` deletes rows beyond the 10 most recent.

**3. AppDatabase.kt** -- Create new file:

```kotlin
package com.example.yt2local.data.db

import androidx.room.Database
import androidx.room.RoomDatabase

@Database(entities = [DownloadHistoryEntity::class], version = 1, exportSchema = false)
abstract class AppDatabase : RoomDatabase() {
    abstract fun downloadHistoryDao(): DownloadHistoryDao
}
```

`exportSchema = false` suppresses the migration schema export warning. This is appropriate for a v1 app with no planned migrations yet.

**4. AppModule.kt** -- Add Room provisions. Add two new `@Provides` functions AFTER the existing `provideVideoRepository` function:

Add imports at the top of the file:
```kotlin
import androidx.room.Room
import com.example.yt2local.data.db.AppDatabase
import com.example.yt2local.data.db.DownloadHistoryDao
```

Add provisions:
```kotlin
    @Provides
    @Singleton
    fun provideAppDatabase(@ApplicationContext context: Context): AppDatabase {
        return Room.databaseBuilder(
            context,
            AppDatabase::class.java,
            "yt2local.db"
        ).build()
    }

    @Provides
    @Singleton
    fun provideDownloadHistoryDao(db: AppDatabase): DownloadHistoryDao {
        return db.downloadHistoryDao()
    }
```

The database is scoped as `@Singleton` -- only one connection throughout app lifetime. The DAO is also `@Singleton` because it comes from the singleton database.

<objective>
Replace all scattered `mutableStateOf` fields in MainViewModel with a single `StateFlow<DownloaderUiState>` data class, and update MainScreen to collect it with `collectAsStateWithLifecycle()`.

Purpose: The current ViewModel has ~11 `var x by mutableStateOf(...)` fields scattered across the class. This is Compose-coupled (untestable outside Compose), not safely read-only (anyone with a reference can observe mutations), and requires `withContext(Dispatchers.Main)` for every state update from background coroutines. `StateFlow` solves all three: testable without Compose, exposed as read-only `StateFlow`, and `MutableStateFlow.update{}` is thread-safe from any dispatcher.

Output: Rewritten MainViewModel state management, updated MainScreen consumption. No new files created.
</objective>

**4. Convert every state mutation** — Replace every direct field assignment with `_uiState.update { it.copy(...) }`.

Key conversion patterns:

**Simple assignments** like `appState = AppState.READY` become:
```kotlin
_uiState.update { it.copy(appState = AppState.READY) }
```

**Multiple assignments** in the same block become a single `update` call:
```kotlin
// Before:
appState = AppState.READY
statusMessage = "Ready to download"
// After:
_uiState.update { it.copy(appState = AppState.READY, statusMessage = "Ready to download") }
```

**Reading current state** like `if (appState == AppState.UPDATING)` becomes:
```kotlin
if (_uiState.value.appState == AppState.UPDATING)
```

**Thread safety: Remove ALL `withContext(Dispatchers.Main)` blocks that ONLY wrap state mutations.** `MutableStateFlow.update{}` is thread-safe from any dispatcher. But keep `withContext(Dispatchers.Main)` if it wraps non-state operations (there are none in this codebase).

**Specific method conversions:**

**`initialize()`:**
- `updateStatus("Initializing YoutubeDL...")` stays as-is (updateStatus will be converted)
- `withContext(Dispatchers.Main) { appState = UPDATING; statusMessage = "..." }` becomes `_uiState.update { it.copy(appState = AppState.UPDATING, statusMessage = "Updating yt-dlp... (tap Skip to proceed)") }` — remove the withContext wrapper
- `withContext(Dispatchers.Main) { if (appState == UPDATING) { ... } }` becomes `_uiState.update { state -> if (state.appState == AppState.UPDATING) state.copy(appState = AppState.READY, statusMessage = "Ready to download") else state }` — conditional update inside the lambda

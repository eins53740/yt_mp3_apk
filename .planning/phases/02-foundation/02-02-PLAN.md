**1. Create `di/AppModule.kt`** — New file providing VideoRepository as a Hilt singleton.

Create the directory `app/src/main/java/com/example/yt2local/di/` and the file:

```kotlin
package com.example.yt2local.di

import android.content.Context
import com.example.yt2local.VideoRepository
import dagger.Module
import dagger.Provides
import dagger.hilt.InstallIn
import dagger.hilt.android.qualifiers.ApplicationContext
import dagger.hilt.components.SingletonComponent
import javax.inject.Singleton

@Module
@InstallIn(SingletonComponent::class)
object AppModule {

    @Provides
    @Singleton
    fun provideVideoRepository(@ApplicationContext context: Context): VideoRepository {
        return VideoRepository(context)
    }
}
```

**Why `@Singleton`:** VideoRepository holds no mutable state (just a Context reference for yt-dlp operations). One instance shared across ViewModel and future Service is correct. `@ApplicationContext` is critical — `@ActivityContext` would leak.
